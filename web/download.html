📱 Panduan Pemasangan APK di HP Android (Tanpa Play Store)

  1. Ketuk tombol "Download Aplikasi (SocioDetective.apk)" di atas melalui browser HP Android Anda (disarankan Google Chrome).
  2. Tunggu hingga file SocioDetective.apk selesai diunduh, lalu ketuk file tersebut dari notifikasi unduhan atau folder Download / File Saya.
  3. Jika muncul peringatan Android berbunyi "Demi keamanan, ponsel Anda tidak diizinkan menginstal aplikasi tidak dikenal dari sumber ini", ketuk Setelan (Settings).
  4. Aktifkan sakelar "Izinkan dari sumber ini" pada Chrome atau Pengelola File, lalu tekan tombol kembali.
  5. Ketuk Instal / Pasang dan tunggu beberapa detik hingga selesai.
  6. Ikon SocioDetective akan muncul di layar utama HP Anda dan dapat dijalankan layaknya aplikasi Android lainnya.
